This paper proposes Matrix Encryption Walks (MEW), a symmetric stream cipher designed for constrained environments such as IoT and smart devices. The algorithm uses graph walk traversals across a 2-dimensional matrix to generate keystreams, XOR-combined with plaintext, operating in linear time complexity with minimal memory overhead.

A comprehensive security analysis covers Shannon entropy, avalanche effect, key space cardinality, and resistance to chosen and known plaintext-ciphertext attacks. Proof-of-concept implementation code accompanies the paper.
